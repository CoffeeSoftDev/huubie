coffeeForm · select con badges

Opción badge: true de un campo select con select2: true: cada opción se pinta como la pastilla de color de las tablas, en la lista y en el valor elegido. Las opciones sin color (ej. "Sin área") quedan en texto plano.

Uso

{
    opc:     "select",
    id:      "warehouse_area_id",
    lbl:     "Área",
    class:   "col-12 col-md-4",
    select2: true,
    badge:   true,
    data: [
        { id: '',   valor: 'Sin área' },
        { id: '18', valor: 'Vitrina', color: '#0F766E', bg: '#CCFBF1' }
    ]
}

Opciones

OpciónDefaultQué hace
select2falseObligatorio para el badge: el select nativo no puede pintar HTML en sus opciones
badgefalsePinta cada opción con su color (texto) y bg (fondo)
data[].color / bg—Hex de cada opción. En inventory los arma areaColors() (conf/_Utileria.php)
