rolePermissions

Ficha de permisos por rol. Lista de roles a la izquierda; a la derecha, las familias plegadas con su contador. Los permisos irreversibles quedan fuera del acordeon.

Uso

this.rolePermissions({
    parent:   'containerPermisos',
    id:       'cmpPermisos',
    theme:    'dark',           // 'dark' | 'light'
    lockedId: 1,                // rol que no se puede editar
    json: {
        roles:       [ { id, name, users, granted } ],
        permissions: [ { id, code, name, description, family, is_dangerous, has_scope } ],
        granted:     {}
    },
    onSelect: (rolId, done) => done({ 1: 'all', 8: 'own' }),
    onSave:   (rolId, granted, done) => done()
});

Opciones

OpcionDefaultQue hace
parent'root'Contenedor donde se monta
theme'light'dark en modulos Huubie
lockedIdnullRol que se muestra sin editar
json.permissions[]has_scope pinta No / Su sucursal / Todas; is_dangerous lo saca del acordeon
onSelectnoopSe dispara al elegir rol; devuelve lo concedido por done()
onSavenoopRecibe (rolId, granted, done)
